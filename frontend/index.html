Calibration, assessment and the intervention queue require a signed-in account. The access token is held in memory only - never in localStorage, which any injected script could read. A page reload loses it, and the page silently exchanges the httpOnly refresh cookie for a new one, so you stay signed in. Sign out revokes the cookie server-side.
